\textbf{\Large{\section*{Abstract}}}

\addcontentsline{toc}{chapter}{Abstract}{}

CampusFlow is a mobile application developed to address the daily challenges faced by students at the AIKTC campus. The basic objective of this project is to centralize communication and academic resources that are currently scattered across unhelpful WhatsApp groups. This is achieved by building a unified ecosystem featuring four distinct modules: a Lost \& Found section, a Project Collaboration hub with real-time chatting, a verified Previous Year Questions (PYQ) Repository, and a centralized Event Calendar. The methodology involves creating a robust and scalable mobile application using XML for the frontend, Java for the backend, Firebase Firestore for real-time database management, and the ImageBB API for lightweight image hosting. The outcome is a streamlined digital community that reduces student anxiety over lost items, boosts innovation through seamless team building, and enhances academic success.
